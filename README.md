## ✨ 功能特性

- **AI驱动的故事生成**：利用大语言模型创造独特的故事线
- **自定义冒险体验**：玩家可指定主题和背景设定
- **多种选择模式**：支持预设选项和自定义行动
- **动态难度调整**：前三轮必有选项，后续轮次按概率结束
- **时间监控**：实时显示AI响应时间
- **灵活部署**：支持云端和本地模型

## 🛠️ 安装步骤

### 环境要求
- Python 3.8+
- pip包管理器

### 安装依赖
```bash
pip install -r requirements.txt
```

## ⚙️ 配置说明

### 创建环境变量文件
创建 `.env` 文件并填入相应参数：

```env
API_KEY=your_api_key_here
BASE_URL=your_base_url_here
MODEL=your_model_name_here
```

### 接入大模型

#### 方案一：云端大模型
获取API密钥后，在 `.env` 文件中配置：
- `API_KEY`: 你的API密钥
- `BASE_URL`: 你的API基础URL
- `MODEL`: 你的模型名称

#### 方案二：本地大模型
使用Ollama等本地模型，在 `.env` 文件中配置：
- `BASE_URL`: `http://localhost:11434/v1` （本地模型地址）
- `API_KEY`: `ollama` （任意非空值）
- `MODEL`: 你的模型名称

## 🎮 游戏玩法

1. **开始游戏**：运行 `python textGame.py`
2. **设置冒险**：输入主题和背景简介
3. **选择行动**：
   - A/B/C：选择预设选项
   - D：输入自定义行动
4. **推进故事**：跟随AI生成的情节继续冒险
5. **迎接结局**：随机概率触发游戏结局
